# C盘清理大师

一款安全可靠的 Windows C 盘垃圾文件清理工具，基于 Python + CustomTkinter 构建。

## 功能特性

- **彻底扫描（v3.1 重点）**：内置 58+ 类垃圾清理规则，覆盖临时文件、浏览器缓存、系统缓存、开发环境缓存（npm/pip/NuGet/Go/Cargo/Node）、应用缓存（NVIDIA/Teams/Spotify/Adobe/Zoom/游戏平台）等；并新增**全盘残留临时文件清扫**（按扩展名递归扫描用户目录，自动跳过系统/个人文档目录）
- **系统级深度清理（需管理员）**：WinSxS 组件存储清理（Dism，等同"Windows 更新清理"，常释放数 GB）、系统还原点、休眠文件（hiberfil.sys）、Windows.old 升级残留
- **安全保护**：多层保护机制，杜绝误删系统关键文件
- **隔离模式（默认开启）**：清理不再永久删除，文件先移入隔离区，支持一键恢复（撤销），彻底杜绝误删不可逆
- **清理前确认清单**：实际清理前弹出确认框，列出待清理类别、数量与大小，绝不静默删除
- **大文件迁移（v3.3 独立子菜单）**：「分析」已拆为两个并列子菜单 —— 📊 C盘分析（目录占用/大文件/重复文件/空文件夹）与 📦 文件迁移（选文件 → 迁移到其他盘，结果在本页可见）；禁止迁移系统/受保护文件，杜绝误删
- **管理员提权提示**：未以管理员运行时显示横幅，可一键"以管理员重启"
- **恢复站**：独立 Tab 列出所有被隔离项，可一键恢复或永久清除
- **一键清理**：选中类别后一键清理，支持取消操作
- **自动清理**：支持每天/每周/每月定时自动清理（同样走隔离模式）
- **现代界面（v3.3 重构）**：全新品牌图标（窗口/任务栏/侧栏统一）；左侧「分组导航栏」——品牌区 + 主菜单 + 分析工具（📊C盘分析 / 📦文件迁移 两个并列子菜单）+ 底部权限状态，字号更大、间距更宽松、当前项高亮，整体更大气美观；卡片化功能分区层次清晰；底部全局状态栏跨页面显示最近操作
- **概览仪表盘（v3.2 新增）**：C 盘空间环形图、总容量/已用/可用/可清理(估) 四项统计、系统健康评分（按使用率动态变色）、快捷操作（快速扫描 / 智能清理 / 空间分析）
- **智能清理（v3.2 新增）**：一键扫描后仅自动勾选安全类别（非系统级、非高危）并进入确认，隔离模式下可一键恢复
- **实时日志**：所有操作均有日志记录，并同步至底部状态栏

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 1. 直接运行
```bash
python main.py
```

### 2. 以管理员身份运行（推荐）

右键点击命令提示符 → 以管理员身份运行 → 执行上述命令。

> 管理员权限可获得更完整的扫描结果，特别是系统临时文件和回收站。

### 3. 操作流程

1. **扫描**：点击「扫描」按钮，自动检测 C 盘各类垃圾文件
2. **选择**：在列表中勾选要清理的类别（默认全选）
3. **清理**：点击「一键清理」执行清理操作
4. **查看**：底部日志区域显示清理结果

## 支持的清理类别

> 共 58+ 类，以下为分组概览（快速清理 + 深度清理 + 系统级命令清理）。

**快速清理（常用、安全）**：Windows 临时文件、回收站、Chrome/Edge/Firefox 浏览器缓存、Windows 更新缓存、预读取文件、缩略图缓存、Windows 错误报告、DirectX 着色器缓存、传递优化文件。

**深度清理（应用/开发缓存）**：Windows 日志与调试残留、内存转储、Windows 升级残留、应用商店缓存、通知缓存、微信/QQ 缓存（默认关闭防误删）、Office 缓存、OneDrive 缓存、Steam/Discord/剪映/迅雷/WPS/PotPlayer/钉钉 缓存、pip/npm/yarn/Maven/Gradle/conda/VS Code/Docker 等开发缓存，以及 **Brave/Opera/Vivaldi/Yandex 浏览器、Node/.NET NuGet/Go/Cargo/Python 编译缓存、NVIDIA/AMD 着色器、Teams/Spotify/Adobe/Zoom/百度网盘/游戏平台缓存** 等。

**全盘残留临时文件清扫（v3.1 新增）**：按扩展名（`.tmp/.bak/.old/.cache/.log/.etl` 等）递归扫描用户目录与系统日志目录，自动跳过系统关键目录与个人文档目录，安全捕获散落各处的残留临时/备份文件。

**系统级命令清理（需管理员，高危项默认关闭）**：

| 类别 | 说明 | 风险 |
|------|------|------|
| WinSxS 组件存储清理 | Dism 清理已取代的旧版本，常释放数 GB（安全） | 低 |
| 系统还原点清理 | 删除所有卷影副本（释放大，但失去还原能力） | 高（默认关） |
| 休眠文件清理 | 关闭休眠并删除 hiberfil.sys（≈内存大小） | 高（默认关） |
| Windows.old 升级残留 | 删除升级遗留文件夹 | 高（默认关） |

> 系统级清理均需在**以管理员身份运行**时才能扫描/执行；非管理员时仅提示，不会误删。

## 安全保护机制

**三层防护，绝不误删：**

1. **隔离模式（默认开启）**：清理时文件先移动到 `%LOCALAPPDATA%/CCleaner/quarantine`，而非直接永久删除。可在「恢复站」Tab 一键还原到原路径；确认无误后再手动「永久清除」。关闭隔离模式才会真正删除。
2. **清理前确认清单**：点击「一键清理」执行真实删除前，会弹出确认框，列出每个待清理类别的文件数、占用大小，并提示当前是隔离模式还是永久删除模式，必须确认才继续。
3. **硬保护黑名单**：以下内容绝对不会被清理：
   - `C:\Windows\System32` 及所有子目录
   - `C:\Windows\SysWOW64`
   - `C:\Program Files`、`C:\Program Files (x86)`
   - Windows 核心文件（.dll、.sys、.exe 等）
   - 引导文件（bootmgr、BCD 等）
   - 注册表文件
   - 任何正在被进程占用的文件
   - 大文件（>4GB 默认跳过，防误删虚拟机/ISO/备份）
